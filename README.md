
# AI-Based Smart Irrigation System Using Machine Learning

## Project Overview
This project uses machine learning to predict irrigation needs based on soil moisture and weather conditions.

## Objectives
- Reduce unnecessary water usage.
- Support smart agriculture.
- Predict irrigation requirements.
- Demonstrate machine learning in agriculture.

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn

## Features
- Soil moisture input
- Temperature and humidity input
- Rainfall input
- Crop selection
- Irrigation prediction

## How It Works
Users enter soil and weather conditions. A machine learning model predicts whether irrigation may be needed.

## Future Enhancements
- Real-time soil sensors
- Weather API integration
- Automatic water pump control

## Project Status
Development in progress.

## Disclaimer
This is an educational prototype using sample data. It is not connected to real sensors or a water pump.
